# Anchr

Eine macOS App, die alle paar Minuten per Screenshot schaut, woran man gerade
arbeitet, das gegen die aktuelle Aufgabe prüft, und bei Abweichung nachfragt,
statt einfach zu blocken. Wenn man abdriftet, wird die Aufgabe nicht verteidigt,
sondern kleiner und konkreter gemacht.

Sehr früher Stand. Es gibt noch keinen Code, nur ein Brainstorming.

Siehe [BRAINSTORM.md](BRAINSTORM.md).
